The IoT-based smart night patrolling robot is an autonomous system designed to patrol designated areas, capturing images and videos using a camera module while utilizing ultrasonic sensors to detect obstacles and prevent collisions. A sound sensor detects unusual sounds and alerts users, while a buzzer provides an audible alarm in case of disturbances. Equipped with a motor driver and motors controlled by an Arduino Uno, the robot moves and changes direction autonomously, with a NodeMCU module providing internet connectivity for remote monitoring and control through a web-based interface. This low-cost system integrates hardware and software, including infrared and ultrasonic sensors for 360-degree sensing and environmental monitoring, as well as a robust chassis for mobility. The robot processes data, executes navigation algorithms, and adapts to dynamic environments using a centralized microcontroller, making autonomous decisions and following predefined patrol routes with precision. Designed for surveillance and security, it exemplifies the convergence of robotics and IoT, offering an efficient, effective, and versatile solution for night patrolling and real-time connectivity.
